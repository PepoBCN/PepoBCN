# Josh Feldberg

I build small AI products where every answer traces back to its source, mostly over parliamentary records and the news. I write the specs and build with Claude Code.

Live products:

- [ParlIQ](https://parliq.feldberg.co): plain-English questions on the UK Parliament, every answer cited.
- [AI Burnham](https://burnhamai.feldberg.co): the UK Prime Minister's public record, with every quote checked word for word against its source.
- [Hansard connector](https://hansard-mcp.feldberg.co): an MCP server I built and host that gives AI assistants sourced access to Hansard. Code in [hansard-mcp](https://github.com/PepoBCN/hansard-mcp).

Code here:

- [parliament-mcp](https://github.com/PepoBCN/parliament-mcp): an MCP server for ParlIQ with live end-to-end tests.
- [ship-check](https://github.com/PepoBCN/ship-check): checks that a live app serves real data, catching pages that return 200 with nothing in them.

hansard-mcp is live UK Parliament data (Hansard, votes, bills, members) for any AI assistant. parliament-mcp is ParlIQ's select committee evidence as 14 tools.

Side projects: [b-side](https://github.com/PepoBCN/b-side), a free Mac app that plays YouTube as your wallpaper on every screen, with sound.

Before this, almost 20 years leading digital and communications work for the UK Parliament, the UN, foundations and large networks, including disinformation research for the DCMS Select Committee.
