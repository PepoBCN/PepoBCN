# Josh Feldberg

I build small AI products where every answer traces back to its source, mostly over parliamentary records and the news. I write the specs and build with Claude Code.

Live products:

- [ParlIQ](https://parliq.feldberg.co): plain-English questions on the UK Parliament, every answer cited. Used by the team of former DCMS committee chair Damian Collins.
- [AI Burnham](https://burnhamai.feldberg.co): the UK Prime Minister’s public record, with every quote checked word for word against its source.
- [Hansard connector](https://hansard-mcp.feldberg.co): an MCP server I host, built on an open-source package, that gives AI assistants sourced access to Hansard.

Code here:

- [EUParlIQ](https://github.com/PepoBCN/EUParlIQ): cited answers over European Parliament records.
- [parliament-mcp](https://github.com/PepoBCN/parliament-mcp): an MCP server for ParlIQ with 14 tools and live end-to-end tests.
- [pepo-feeds](https://github.com/PepoBCN/pepo-feeds): news monitoring feeds across Google News, the Guardian and the New York Times, with duplicates removed.
- [ship-check](https://github.com/PepoBCN/ship-check): checks that a live app serves real data, catching pages that return 200 with nothing in them.

Before this, almost 20 years leading digital and communications work for the UK Parliament, the UN, foundations and large networks, including disinformation research for the DCMS Select Committee.
